# weirdo.neural

App Android para rodar LLMs localmente, com terminal integrado e execução de ferramentas.

## Stack
- Kotlin + Jetpack Compose
- Hilt (DI)
- Room (persistência)
- DataStore (preferências)
- llama.cpp (Etapa 2)
- Chaquopy (Python embarcado, Etapa 3)
